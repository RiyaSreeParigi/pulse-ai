# PULSE AI

## Created by
**Riya Sree Parigi**

## About

PULSE AI is an AI-powered health monitoring platform designed to work with a smart pendant.

The system aims to:
- Monitor health continuously
- Detect unusual patterns early
- Display live health data
- Provide AI-powered insights
- Store historical health reports
- Help users understand their wellbeing

This repository contains the frontend, backend, AI modules, and documentation for the PULSE platform.
